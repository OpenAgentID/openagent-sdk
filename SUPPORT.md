# Support

| You need | Go to |
|---|---|
| How-to questions | The [OpenAgentID docs](https://docs.openagent.id) and [Discussions](https://github.com/OpenAgentID/openagent-sdk/discussions) |
| A bug or a feature request | [Open an issue](https://github.com/OpenAgentID/openagent-sdk/issues/new/choose) |
| A security issue | [SECURITY.md](SECURITY.md): report privately, never in a public issue |
| Releases and verification | [docs/RELEASING.md](docs/RELEASING.md) and the [GitHub releases](https://github.com/OpenAgentID/openagent-sdk/releases) |

Maintainers triage new issues within 3 business days.
