# OpenAgentID 0.7.1: refined accessories

This patch polishes the shared glasses and headphones across all 17 families and
62 kinds. Autos remains the default, with no accessories selected automatically.

Glasses have slimmer contrasting metal rims, lighter temples and small hinge
details. Transparent lenses keep their fixed 62 × 116 dimensions while the frame
follows the eyes. Temple endpoints stay connected to the sides of the head.
Headphones have a slimmer band and layered ear cushions with restrained highlights,
inside the existing exterior fit and crop envelope. Both flat and plush characters,
on-face and raised eyes, use the same accessories.

Eye motion, expressions, status updates, crop geometry and stored appearance
contracts are unchanged. No migration or new configuration is required.
