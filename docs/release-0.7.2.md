# OpenAgentID 0.7.2: a brighter character collection

All 17 families and 62 kinds use clearer, more saturated pigments. Autos and
SpaceX share eight blue, cyan, orange, red, green, gold, violet and pink seed
slots. The other families keep their own characteristic silhouettes and curated
accent combinations, using the same bright visual direction. Holiday kinds keep
recognizable pumpkin orange, harvest gold, Christmas red/green and snowy blues.

The plush material restores 35% of the original pigment after its fiber and
volume lighting. This preserves the soft texture without compounding darkening.
The same finish applies to the body and raised eye pods. Flat rendering also
receives the new curated colors.

This is an intentional visual palette update: the same DID may now display a
different RGB color. DID hashing, seed-slot selection, shape selection, identity
documents and verification are unchanged. Stored appearance schemas, HTTPS avatar
overrides, eye expressions, live status updates, accessories and stable face crops
are preserved. Autos remains the default. No new configuration is required.
